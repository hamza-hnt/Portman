# Portman identity

`portman-logo.png` is the transparent logo: a mint **P** surrounding a lavender
terminal prompt. The TUI uses a compact single-line `[>_]` mark in the same
colors, with ASCII characters that work without image protocols or patched
fonts. It preserves the terminal's background and transparency.

Palette: mint `#70E1C3`, lavender `#B6A0F5`, amber `#F4C77E`, coral `#FF8495`,
slate `#858CA5`, light ink `#E4E7F2`. Selection uses dark teal `#1D3539`.
Color is always paired with a label, pointer, checkbox, or state indicator.

Generated with the built-in ImageGen tool. Final prompt:

> Use case: logo-brand. Asset type: small standalone logo icon for Portman, a macOS developer terminal tool for managing local ports and projects. Primary request: design one polished, memorable compact monogram P that subtly suggests a network socket and a terminal prompt. Style: crisp flat vector-like geometry, bold monoline silhouette with softly squared corners, readable at 24–32 pixels. Make the upper bowl of the P feel like a socket opening, with a small restrained connector/cursor accent. Palette from the app: mint #70E1C3 as the primary shape, a small lavender #B6A0F5 accent. Composition: one centered icon, roughly 70% of a square canvas, generous transparent margins. Transparent background, including all negative space. No wordmark, no text beyond the abstract P silhouette, no presentation board, no gradient, no shadows, no mockups, no extra symbols, no watermark. The result should feel quietly technical and crafted rather than playful.
